# App Store Optimization

## Status

This capability is unavailable with the current Muapi SEO tool set. The
registered tasks cover web search, local search, AI visibility, and YouTube;
they do not provide app-store search rankings, listing conversion data, or
store-specific metadata signals.

## Required behavior

When a user asks for app-store optimization, state the missing data boundary
and stop. Do not use web keyword volume as a substitute for app-store volume,
and do not invent ranking or conversion observations.

This file remains as a clear extension point for a future Muapi app-store
integration.
